# 일차별 개발 진행

기준: 2026-11-07 확인 당시. [기획서 6.2.4 일정](https://docs.google.com/document/d/1Y8ZQw0Hr8II-M7drDmApz_opwwH_2sNFR54sO2Z4cPU/edit)은 착수일과 작업시간이 정해지지 않은 상대 작업일 1~60일의 참고 계획입니다. 실제 달력상 개발 일차를 확인할 근거는 없으며, 아래 상태는 작업 범위와 구현 상황의 대조입니다. 앞당겨 구현한 내용이 있어도 각 일차의 완료 기준을 모두 만족했다는 뜻은 아닙니다.

20일차 Unity 검증 복사본에서 편집 모드 29개와 플레이 모드 전체 135개가 통과했습니다. 전체 회귀는 새 HUD 시험의 설정 격리 보완 전이며 보완 후 HUD 포커스 시험 4개를 별도로 재실행해 통과했습니다. 복사본 맵·시작 설정은 아래 19일차 조건과 같고 각 시험은 복제 설정을 사용했습니다. 원본 씬과 설정 에셋은 보존했으며 실제 화면·실물 입력·수동 플레이와 성능은 미검증입니다.

19일차 검증 복사본의 편집 모드 29개와 다중 사망·재진입 수집·반복 재시작·대상 자식 Collider·무기 및 스킬별 사망·트리거 장애물 사례를 포함한 플레이 모드 전체 131개가 통과했습니다. 전체 131개는 사용자 설정 격리 보완 전 결과이며, 보완 후 상호작용 플레이 모드 시험 21개를 별도로 다시 실행해 모두 통과했습니다. 검증 복사본은 `Map` 루트 `(3, -2)`, 바닥 16×10과 다른 스프라이트, 시작 `Staff`·체력 137·공격력 13·슬라임 6마리·Q 빈값·E/R 중복이며, 각 시험은 독립 설정을 사용합니다. 원본 씬과 설정 에셋은 보존하며 실물 입력·화면·수동 플레이와 성능은 미검증입니다.

18일차 검증 복사본에서 편집 모드 28개와 플레이 모드 110개 테스트가 통과했습니다. 복사본 맵은 루트 `(3, -2)`·바닥 16×10과 다른 스프라이트이고 시작 설정은 `Staff`, 체력 137·공격력 13, 슬라임 6마리, Q 빈값·E/R 중복입니다. 개별 시험은 씬 인스턴스와 설정 복제본을 사용했습니다. 이전 설정 사본의 회피 기본값과 기존 값도 검사했습니다. 원본 씬과 설정 에셋은 변경하지 않았으며 실물 입력·화면·수동 플레이와 성능은 미검증입니다.

17일차 변경을 반영한 Unity 프로젝트 검증 복사본에서 편집 모드 23개와 플레이 모드 80개 테스트가 통과했습니다. 복사본 맵은 루트 `(3, -2)`, 바닥 16×10과 다른 스프라이트이고 기본 설정은 `Staff`, 체력 137·공격력 13, 슬라임 6마리, Q 빈값·E/R 중복입니다. 시험은 씬 인스턴스와 독립 설정 복제본을 사용하며 원본 씬과 설정 에셋은 변경하지 않았습니다. 실물 키보드·마우스와 화면, 수동 플레이 및 성능은 검증하지 않았습니다.

16일차 변경을 반영한 Unity 프로젝트 검증 복사본에서 `Map` 루트를 `(3, -2)`, 바닥을 16×10과 다른 스프라이트로 바꾸고 시작 무기 `Staff`, 플레이어 체력 137·공격력 13, 슬라임 6마리로 설정했습니다. 이 조건에서 편집 모드 18개와 플레이 모드 66개 테스트가 통과했습니다. 변경 소스 7개의 SHA-256은 원본과 복사본이 일치했고 원본 설정 에셋은 Git 변경이 없습니다. 실물 마우스·키보드와 실제 화면, 다중 해상도 및 성능은 검증하지 않았습니다.

이후 별도 검증 복사본의 설정 에셋에 Q 빈값과 E/R 중복을 저장한 상태에서 전체 플레이 모드 테스트 67개가 통과했습니다. 스킬 시험 설정을 독립 복제하는 픽스처를 사용해 기존 전투와 재시작도 검증했습니다.

프로젝트 복사본에서 전투 씬을 첫 씬으로 지정한 Windows 빌드가 성공했습니다. 생성된 빌드 폴더는 요청에 따라 삭제했으며, 당시 빌드의 실제 실행과 수동 조작은 미검증입니다.

15일차 무기 선택 변경을 반영하고 맵 위치·크기·스프라이트를 시험용으로 변경한 Unity 프로젝트 복사본에서 편집 모드 테스트 12개와 플레이 모드 테스트 61개가 통과했습니다. 별도 검증 복사본에서 시작 무기를 `Staff`, 플레이어 체력 137·공격력 13, 슬라임 6마리로 변경한 조건에서도 플레이 모드 61개가 통과했고 설정 에셋의 SHA-256은 테스트 전후 동일했습니다. 원본 에셋은 변경하지 않았습니다. 실제 마우스와 여러 해상도의 화면 검증 및 성능 측정은 남았습니다.

14일차 지팡이 변경을 반영한 Unity 프로젝트 복사본의 최종 편집 모드 테스트 12개와 맵 위치·크기·스프라이트를 시험용으로 변경한 복사본의 플레이 모드 테스트 52개가 통과했습니다. 13일차에는 기본 맵에서도 편집 모드 12개와 플레이 모드 36개가 통과했습니다. 화살 가장자리와 정지 벽의 스침 테스트는 수정 전 실패를 재현한 뒤 수정 후 통과했습니다. 별도 복사본에서 맵 위치·크기·스프라이트를 변경한 조건에서도 편집 모드 12개와 플레이 모드 36개가 모두 통과했습니다. 1도 회전한 경계의 오류 처리는 수정 전 실패를 재현하고 수정 후 재검증했습니다. 씬이 없는 복사본에서 실행한 배치 검증은 오류 로그·씬 미생성·빌드 설정 해시 불변을 확인했습니다. 실제 화면·마우스 수동 플레이와 성능은 미검증입니다. 설정 에셋 참조 문제는 실패를 재현한 뒤 수정하고 재검증했으며, 사용자가 지정한 다른 설정 참조를 보존하는 편집 모드 테스트도 수행했습니다.
