# 일차별 개발 진행

기준: 2026-11-06 확인 당시. [기획서 6.2.4 일정](https://docs.google.com/document/d/1Y8ZQw0Hr8II-M7drDmApz_opwwH_2sNFR54sO2Z4cPU/edit)은 착수일과 작업시간이 정해지지 않은 상대 작업일 1~60일의 참고 계획입니다. 실제 달력상 개발 일차를 확인할 근거는 없으며, 아래 상태는 작업 범위와 구현 상황의 대조입니다. 앞당겨 구현한 내용이 있어도 각 일차의 완료 기준을 모두 만족했다는 뜻은 아닙니다.

13일차 활 변경을 반영한 기본 맵의 Unity 프로젝트 복사본 자동 검증에서 편집 모드 12개와 플레이 모드 36개가 통과했습니다. 화살 가장자리와 정지 벽의 스침 테스트는 수정 전 실패를 재현한 뒤 수정 후 통과했습니다. 별도 복사본에서 맵 위치·크기·스프라이트를 변경한 조건에서도 편집 모드 12개와 플레이 모드 36개가 모두 통과했습니다. 1도 회전한 경계의 오류 처리는 수정 전 실패를 재현하고 수정 후 재검증했습니다. 씬이 없는 복사본에서 실행한 배치 검증은 오류 로그·씬 미생성·빌드 설정 해시 불변을 확인했습니다. 실제 화면·마우스 수동 플레이와 성능은 미검증입니다. 설정 에셋 참조 문제는 실패를 재현한 뒤 수정하고 재검증했으며, 사용자가 지정한 다른 설정 참조를 보존하는 편집 모드 테스트도 수행했습니다.

## 일정 적용 기준

- 1일차의 오래된 시점 미결정 표현보다 구체적인 2D 탑뷰 명세를 따릅니다.
- 22일차의 오래된 자폭형·지원형 문구를 이유로 새 적을 추가하지 않습니다. 상세 일반 적 목록은 슬라임·고블린·스켈레톤 궁수·오크 전사·늑대입니다.
- 던전과 적 배치는 구역 진입·목표 달성·상호작용 등 조건을 기준으로 합니다. 출정 시간 목표나 타이머를 사용할 수 있으나, 경과 시간마다 몬스터 종류를 강제로 바꾸지는 않습니다.
- 활은 상세 무기 명세의 직선 투사체·최초 1대상·비관통을 우선합니다. 유저 거래소·캐시·AI 자동 경제 조정과 협동은 후속 단계입니다.
- 일차별 완료 표시는 구현과 해당 검증 근거가 확인된 뒤 갱신합니다. 기획서의 일정은 확정 납기나 실제 경과 일수를 뜻하지 않습니다.
