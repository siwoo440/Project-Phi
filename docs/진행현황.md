17일차 프로젝트 검증 복사본에서 편집 모드 23개와 플레이 모드 80개 테스트가 모두 통과했습니다. 복사본의 `Map` 루트는 `(3, -2)`, 바닥은 16×10과 다른 스프라이트이며 기본 설정은 `Staff`, 체력 137·공격력 13, 슬라임 6마리와 Q 빈값·E/R 중복입니다. 개별 시험은 씬 인스턴스와 독립 복제 설정에 필요한 값을 지정합니다. 자동 테스트는 가상 Q/E/R 입력, 화염탄 최초 적·벽 가림·발사 후 무기 변경, 회오리 대상·벽 가림, 치유량·만피 처리, 마나·쿨다운, 슬롯 재배치, 입력 포커스와 재시작을 포함합니다. 이전 형식 설정 사본의 17일차 기본값과 기존 값 보존도 검사했습니다. 원본 씬과 설정 에셋은 변경하지 않았습니다. 실물 마우스·키보드, 실제 화면·수동 플레이, 성능은 미검증이며 새 변경으로 독립 빌드를 실행하지 않았습니다.

16일차에는 12종의 공용 스킬 후보와 설정 에셋의 Q/E/R 시작 슬롯, 무기와 분리된 실행 상태 및 영문 상태 안내를 구현했습니다. 빈 값·미등록 값·중복은 해당 슬롯을 비활성화하고 오류를 표시하며, 기존 이동과 무기 전투는 유지합니다. 에셋은 자동 수정하지 않고 재시작 시 시작 조합을 다시 읽습니다.

16일차 변경을 반영한 Unity 프로젝트 검증 복사본에서 `Map` 루트를 `(3, -2)`, 바닥을 16×10과 다른 스프라이트로 바꾸고 시작 무기 `Staff`, 플레이어 체력 137·공격력 13, 슬라임 6마리로 설정했습니다. 이 조건에서 편집 모드 18개와 플레이 모드 66개 테스트가 통과했습니다. 변경 소스 7개의 SHA-256은 원본과 복사본이 일치했고 원본 설정 에셋은 Git 변경이 없습니다. 후보·슬롯 검증, 이전 형식의 설정 사본 로드, 무기 전환과 재시작, 오류 슬롯에서도 기존 무기 전투가 유지되는 흐름을 자동 검증했습니다. 이관 테스트는 복제 에셋만 임시 수정한 뒤 삭제합니다. 실제 마우스·키보드와 다중 해상도의 화면 UI, 수동 플레이와 성능은 검증하지 않았습니다.

이후 별도 검증 복사본의 설정 에셋에 Q 빈값과 E/R 중복을 저장한 상태에서 전체 플레이 모드 테스트 67개가 통과했습니다. 새 픽스처는 스킬 시험 설정을 독립 복제하여 기존 전투와 재시작 테스트가 사용자 설정을 수정하지 않고 실행되도록 격리합니다.
