## 첫 단계

`Assets/Phi/Scripts`에 전투 코드와 설정 데이터가 작성됐고 `Assets/Phi/Scenes/CombatPrototype.unity`와 `Assets/Phi/Data/PrototypeSettings.asset`이 제공됩니다. 에디터 메뉴 `Phi > Open Combat Prototype`은 저장된 시험 씬을 열고 빌드 목록에 등록합니다. 씬이 없으면 오류를 표시하고 새 씬을 만들지 않습니다. 조작과 실행 절차는 [README](../README.md)에 기록했습니다. 기존 Unity 프로젝트에서 컴파일을 확인했습니다.

14일차 지팡이 변경을 반영한 Unity 프로젝트 복사본의 최종 편집 모드 테스트 12개와 맵 위치·크기·스프라이트를 시험용으로 변경한 복사본의 플레이 모드 테스트 52개가 모두 통과했습니다. 이후 추가한 지팡이 폭발의 거리 동률·슬라임 생성 순서 테스트 1개도 별도로 통과했습니다. 13일차에는 기본 맵에서도 편집 모드 테스트 12개와 플레이 모드 테스트 36개가 통과했습니다. 정지한 벽에 화살 가장자리가 닿는 테스트는 수정 전 실패를 재현했고 수정 후 통과했습니다. 별도 복사본에서 맵의 위치·크기·스프라이트를 변경한 조건에서도 편집 모드 12개와 플레이 모드 36개가 모두 통과했습니다. 경계를 1도 회전한 잘못된 맵을 거부하는 테스트는 수정 전 실패를 재현했고 수정 후 통과했습니다. 씬 파일이 없는 복사본에서 배치 실행 시 오류 로그를 확인했으며 씬 파일은 생성되지 않았고 빌드 설정의 SHA-256도 실행 전후 동일했습니다. 설정 에셋 참조 누락은 실패 테스트로 재현한 뒤 수정해 통과를 확인했고, 사용자가 지정한 다른 설정 참조 보존도 편집 모드 테스트로 확인했습니다. 맵 경계의 플레이어·슬라임 이동 제한, 카메라 시야와 추적, 테두리·조준·체력 표시도 자동 테스트했습니다. 플레이 모드 테스트는 가상 마우스 홀드 공격으로 슬라임 체력이 50 → 29 → 8 → 0으로 감소하는 과정, 슬라임 공격에 따른 플레이어 사망과 재시작 후 플레이어 체력 100·슬라임 체력 50 초기화를 확인했습니다. 가상 마우스로 UI 위에서 시작한 드래그의 공격 차단, 놓은 뒤 새 클릭, 재시작 버튼 좌표 클릭도 검증했습니다. 헤드리스 환경에서 처음에는 포커스가 없어 가상 입력이 무시됐으며, 테스트에만 포커스 설정을 적용한 뒤 통과했습니다. 기존에 씬 생성 메서드를 배치로 실행한 기록은 있으나 현재 메뉴는 제공된 씬을 열고, 맵을 생성하지 않습니다.

13일차에는 에셋의 `startingWeapon`으로 검·활을 선택하고 시작하는 기능과 활의 직선 비관통 투사체·장애물 및 맵 외곽 충돌을 구현했습니다. 14일차에는 `Staff` 선택과 지팡이 마법탄·범위 폭발을 추가했습니다. 마법탄은 적이나 사거리 끝에서 폭발하며, 벽이나 씬 외곽에서는 폭발 없이 소멸하는 임시 정책을 사용합니다. 적 충돌 시 폭발 중심은 접촉면이 아닌 마법탄 중심이며 표시 링은 실제 판정 반경보다 약간 안쪽인 근사 표현입니다. 현재 인게임 무기 교체와 투사체 풀링은 미구현입니다. 낮은 FPS에서 움직이는 적과 화살·마법탄의 상대 운동에 따른 스침 판정은 미검증입니다.

검증용 맵 변경은 복사본에만 적용했으며 원본 사용자 맵을 수정하지 않았습니다. 맵은 씬의 `Map > Map Floor > Boundary Top / Bottom / Left / Right`에 저장됩니다. 바닥의 위치·크기 변경은 자식 경계에 반영되며, 회전 없는 축 정렬이 필요합니다. 기존 설정의 `mapHalfWidth`, `mapHalfHeight`는 보존하지만 사용하지 않습니다. `PhiObstacle` 비트리거 장애물 뒤의 검 적중은 차단하며 플레이어와 슬라임의 내부 장애물 이동 충돌은 미구현입니다. 실제 화면·마우스를 이용한 UI 클릭과 수동 플레이, 성능은 검증하지 않았습니다. 기존 `SampleScene`이 첫 빌드 씬이므로 독립 빌드에서 전투 씬을 기본 시작 씬으로 설정하지 않았습니다.
