# 25일차 적 장애물 경로 처리 계획

**목표:** 씬 장애물을 피해 일반 적이 플레이어에게 접근하고 길이 없으면 안전하게 멈춘다.

**구성:** 씬 맵의 실제 경계와 비트리거 장애물 충돌체를 검사해 전투 중 임시 경로 데이터를 계산한다. 적 이동은 기존 연속 충돌 검사를 거치고, 슬라임 돌진과 늑대 도약은 직선 공격을 유지한다.

**기술:** Unity 6000.3, C#, Unity Test Framework. 기준: `docs/개발계획.md` 25일차.

---
## 작업과 검증

- [x] 씬 벽 우회, 길이 막힌 상태와 장애물 변경 후 재탐색 시험을 작성하고 기존 실패를 확인한다.
- [x] 적의 일반 추격에 실제 충돌체와 경계를 반영한 경로 계산을 연결한다.
- [x] 다섯 적의 우회, 도달 불가, 이동 중 장애물 변경, 기존 직선 공격을 검증한다.
- [x] 전체 EditMode·PlayMode 회귀 시험과 문서·변경 사항을 확인한다.

---
## 제약과 검토

- 맵과 장애물은 씬에 저장하며 경로 계산용 오브젝트를 만들지 않는다.
- 장애물이 플레이어와 적을 완전히 분리하면 벽을 통과하거나 흔들리지 않는다.
- 이동된 장애물과 플레이어 위치를 다시 반영한다.
- 트리거 장애물은 이동 경로를 막지 않는다.
- 공격 예고, 돌진·도약 방향과 플레이어 이동 충돌은 기존 동작을 유지한다.
- 경로 간격·갱신 주기와 대규모 성능은 시험값으로 명시한다.
