# 일차별 전투 보완 계획

**목표:** 선행 구현을 보존하며 2일차 형상관리와 앞선 일차의 전투 결함·맵 경계를 검증하고, 이후 무기 기능을 차례로 확장합니다.

**환경:** Unity 6000.3.21f1, 기존 Input System·URP 2D. 테스트는 원본 에디터가 열려 있으므로 별도 복사본에서 실행합니다.

---
## 작업과 확인

- [x] 원격 브랜치 확인 후 기존 프로젝트를 기준 커밋으로 기록하고 푸시.
- [x] 설정 에셋 연결 누락을 재현하고, 씬 및 생성기 수정을 회귀 테스트로 확인.
- [x] 7일차 테스트 맵 경계의 설정값, 플레이어·슬라임 이동 제한과 시각 표시를 구현하고 확인.
- [x] 일차별 실제 상태와 임시 선택을 문서화하고 테스트 통과 범위만 보고.
- [ ] 변경 단위별 커밋 및 푸시 후 다음 미완료 일차 진행.

---
## 경계 기준

임시 중심 좌표 (0, 0), 반폭 10, 반높이 6 월드 단위를 설정 데이터로 분리합니다. 플레이어, 슬라임 접근과 돌진 위치를 경계 안으로 제한하며, 작은 시험 공간의 임시 도형으로 영역을 표시합니다. 기존 무기 피해와 UI 입력 처리를 유지합니다.

---
## 확인할 위험

씬이 설정 에셋을 참조하지 않아 설정을 바꿔도 실행값이 바뀌지 않는 문제, 경계 모서리나 큰 프레임 간격에서 오브젝트가 영역을 벗어나는 문제, 기존 씬과 사용자의 Unity 에디터 상태를 덮어쓰는 문제를 확인합니다.
