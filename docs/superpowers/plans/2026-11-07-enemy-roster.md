# 22일차 일반 적 5종 구현 계획

**목표:** 기존 슬라임·고블린에 스켈레톤 궁수·오크 전사·늑대를 더해 상세 기획의 일반 적 5종을 전투에서 구분합니다. 오래된 일정의 자폭·지원형은 추가하지 않습니다.

**기획 기준:** 스켈레톤 궁수는 체력 35·공격력 9·방어력 1이며 거리를 유지하다 직선 화살을 발사합니다. 오크 전사는 100·15·5로 도끼 예고 후 전방 부채꼴을 강타합니다. 늑대는 45·9·1로 도약 경로를 예고하고 돌진합니다. 기획서 6.2.4의 22일차 완료 기준은 일반 적 5종입니다.

**임시 정책:** 궁수의 이동속도 1.8, 유지거리 3, 사거리 6, 예고 0.5초, 간격 1.5초, 화살속도 8은 조정 가능한 시험값입니다. 조준 방향은 예고 시 고정하고 비트리거 벽과 맵 경계가 화살을 막습니다. 오크 속도 1, 거리 1.4, 예고 0.7초, 간격 1.8초, 각도 120도는 시험값이며 공격 시 공통 피해식과 벽 가림을 사용합니다. 늑대 속도 2.2, 공격 시작 거리 2.5, 예고 0.45초, 간격 1.8초, 도약 거리 2.5와 속도 7, 적중 거리 0.65는 시험값이며 한 번의 도약은 같은 플레이어에게 한 번만 피해를 줍니다. 늑대·기존 적의 내부 장애물 이동 충돌은 후속 범위입니다.

**호환:** 기존 씬 맵은 저장된 하이어라키를 읽고 생성·수정하지 않습니다. 적 설정과 개체별 실행 상태를 분리하고 기존 무기·스킬과 적 충돌 계층을 공유합니다. 제공된 시험 설정에 새 적 각 1마리만 추가하며 새 필드가 없는 기존 설정은 0마리를 유지합니다. 슬라임 외 적의 보상은 미정이라 슬라임 점액을 지급하지 않습니다.

**검증:** 구현 전 새 적 생성·공격 시험이 실패하는 것을 확인합니다. 시험 설정 복제본에서 세 적의 기획 능력치, 고정 방향 예고와 피해·벽·회피·사망, 모든 적의 공통 무기·스킬 피해, 재시작과 이전 설정 이관을 확인합니다. 마지막에 변경 맵과 고블린 활성 설정을 포함한 별도 Unity 복사본에서 전체 편집·플레이 모드 회귀를 실행합니다. 실제 화면·실물 입력과 성능은 별도로 기록합니다.

**추가 요청:** 기획서의 검·활·지팡이·슬라임 점액 PNG를 현재 무기 선택 버튼과 시험 전리품에 적용합니다. 이미지 에셋을 로드할 수 없으면 기존 글자와 도형을 유지합니다. 원본 기획서의 60일 참고 일정과 실제 진행 상태를 비교하고 미완료 충돌·이미지 검증 등을 포함한 23~64일차 작업과 확인 기준을 개발 계획에 정리합니다.

**실행 결과:** 세 적 생성·공격 시험 4개와 늑대 웅크리기 시험은 구현 전 실패를 확인하고 구현 후 통과했습니다. 새 적 활성 설정이 기존 시험의 플레이어·투사체에 간섭하는 문제는 시험 복제 설정 격리 전 실패와 격리 후 통과로 확인했습니다. 기획서 이미지 연결 시험 2개도 구현 전 실패 후 통과했습니다. 변경 맵과 사용자 설정 복사본에서 편집 모드 31개·플레이 모드 170개가 통과했습니다. 실제 화면·실물 입력·성능은 미검증입니다.
