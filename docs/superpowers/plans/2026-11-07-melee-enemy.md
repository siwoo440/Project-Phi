# 21일차 근접형과 돌진형 적 계획

**목표:** 기존 돌진형 슬라임과 빠른 근접형 고블린의 접근·예고·공격을 구분하고 같은 전투 경로에서 처치할 수 있게 합니다.

**기획:** 6.2.4의 21일차 완료 기준은 근접·돌진 두 유형의 행동 구별입니다. 1.14의 고블린은 체력 40·공격력 10·방어력 1이며 빠르게 접근해 무기를 들어 올린 뒤 베고, 슬라임은 체력 50·공격력 8·방어력 2로 예고 후 돌진합니다.

**임시 정책:** 고블린 속도 2.5, 공격 거리 1.0, 예고 0.35초, 간격 1.0초, 전방 90도는 조정 가능한 시험값입니다. 예고 시 방향을 고정하고 적중 시점에 부채꼴·비트리거 벽 가림을 검사합니다. 공통 피해식과 플레이어 회피 무적을 사용합니다. 고블린 정식 보상은 미정이므로 시험 슬라임 점액을 지급하지 않습니다.

**호환:** 기존 슬라임 코드와 씬 맵·오브젝트를 보존합니다. 검·활·지팡이·회오리·화염탄은 두 적을 동일하게 타격하고 폭발의 거리 동률은 생성 순서를 유지합니다. 기존 설정에 새 고블린 수가 없으면 0으로 유지하며, 제공된 시험 설정에는 1을 명시해 게임에서 확인할 수 있게 합니다. 수치는 설정 에셋에 보관하고 체력·행동 상태는 개체마다 분리합니다.

**검증:** 독립 설정·씬 인스턴스에서 고블린 생성·능력치, 슬라임과 차별되는 빠른 접근 및 예고 후 근접 공격, 공격 회피·벽 가림·재시작, 검·활·지팡이·스킬의 두 적 대상 판정과 슬라임 전리품 분리를 검증합니다. 구현 전 실패와 수정 후 전체 편집·플레이 모드 회귀를 확인하고, 원본 씬과 기존 설정 필드를 보존합니다. 실제 화면·실물 입력·성능은 별도 확인합니다.

## 수행 결과

- 구현 전 세 플레이 모드 시험은 고블린 미생성으로 실패했습니다. 구현 후 근접 적 전용 시험 12개가 통과했습니다.
- 고블린 한 마리가 활성화된 Unity 검증 복사본에서 플레이 모드 전체 147개와 편집 모드 전체 30개가 통과했습니다. 이전 설정 사본에서 고블린 수 0과 기획 능력치 기본값, 기존 필드와 원본 참조 보존을 확인했습니다.
- 시험 씬 맵과 기존 설정 필드는 유지했으며 제공된 설정에 `goblinCount: 1`만 추가했습니다. 실제 화면·실물 입력·수동 플레이와 성능은 미검증입니다.
