# 16일차 공용 스킬 슬롯 계획

**목표:** 공용 스킬 후보에서 서로 다른 세 스킬을 Q/E/R 시작 슬롯에 지정하고 무기와 독립적인 실행 상태로 보관합니다.

**임시 정책:** 마을·안전 구역과 준비 화면이 아직 없으므로 시작 조합은 전투 전 설정 에셋에서 선택합니다. 실행 중 에셋을 수정하거나 스킬을 바꾸지 않습니다. 화염탄·회오리 베기·치유의 빛은 사용자 전달문에 제시된 추천 시험 조합이며 확정 조합이 아닙니다. Q/E/R 발동과 마나·쿨다운·효과는 17일차에 구현합니다.

유효한 공용 목록에 없는 값·빈 슬롯·중복된 슬롯은 해당 슬롯을 비활성화하고 위치를 알리되 기존 이동과 무기 전투는 유지합니다. 원본 설정을 자동으로 고치지 않습니다. 12종 전체는 시험용 후보이며 획득이나 해금을 뜻하지 않습니다. 세 칸을 채우는 것은 이 시험의 제한으로, 일반적인 빈 슬롯 정책은 미결정입니다. 기존 설정과 무기 전환, 씬 맵 하이어라키는 보존합니다.
