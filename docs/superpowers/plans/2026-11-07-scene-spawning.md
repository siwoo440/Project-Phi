# 24일차 적 스폰·밀집 구현 계획

**목표:** 씬에 저장한 위치와 구역 진입 조건으로 일반 적을 생성하고 동시 생존 수를 제한한다.

**구성:** 씬의 시작 지점과 구역 지점에 적 종류를 표시한다. 기존 설정의 시작 수와 구역 지점별 1회의 생성 요청을 처리하며, 장애물이나 다른 대상에 막힌 요청은 안전한 지점이 생길 때까지 대기한다.

**기술:** Unity 6000.3, C#, Unity Test Framework. 기준: `docs/개발계획.md`의 24일차.

---

## 검증과 구현

- [x] 씬에 저장된 시작 지점과 구역 진입 후 일회성 등장, 밀집 상한을 테스트하고 기존 구현의 실패를 확인한다.
- [x] `EnemySpawnPoint`의 종류와 씬 오브젝트를 연결하고 기존 적 생성의 원형 좌표를 제거한다.
- [x] 구역 진입, 빈 지점 재시도, 생존 적 상한, 장애물·플레이어 중첩 방지를 구현한다.
- [x] 기존 설정, 사망·재시작, 다섯 적 종류와 변경된 씬 위치를 확인한다.
- [x] 전체 EditMode·PlayMode 시험과 변경 사항을 검토한다.

---

## 검토 조건

- 구역 진입 반복이나 적 사망이 소진된 요청을 재생성하지 않는다.
- 지점이 막히거나 동시 생존 수가 상한에 도달하면 요청이 사라지지 않는다.
- 지점이 빠지거나 맵 밖에 있어도 코드는 대체 지점을 만들지 않는다.
- 초기 적 이름과 기존 설정 수는 유지한다.
- 맵과 지점은 씬에 저장하며 실행 중 지도나 지점을 생성하지 않는다.
