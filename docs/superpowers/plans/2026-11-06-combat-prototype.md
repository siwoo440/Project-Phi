# 최소 전투 프로토타입 구현 계획

**목표:** 기존 Unity 2D 프로젝트에서 플레이어와 슬라임의 이동·공격·피해·사망·재시작이 연결된 테스트 전투 구현.

**구조:** 기존 Input System과 UGUI 사용. 전투 데이터와 실행 상태 분리, 공통 피해 계산 및 단일 공격당 중복 대상 제거. 기존 SampleScene은 보존하고 별도 테스트 씬 또는 명시적 생성 절차 제공.

**환경:** Unity 6000.3.21f1, C#, Windows PC. 저장소 초기화나 에디터 업그레이드 없음.

---
## 구현과 확인

- [ ] 이동 벡터 정규화, 피해 공식, 검 범위에 대한 편집 모드 테스트 작성.
- [ ] 설정값, 공통 피해 계산, 플레이어 입력과 조준, 카메라, 검 타격 구현.
- [ ] 슬라임 접근·공격·피해·사망, 플레이어 체력·사망 및 재시작 구현.
- [ ] UI 클릭 시 공격 차단 및 임시 도형을 사용하는 테스트 공간 구성.
- [ ] Unity 배치 컴파일과 실행 가능한 자동 테스트 확인; 수동 플레이와 성능 검증은 실제 수행 여부를 구분.
- [ ] README, 개발 계획, 설계 결정, 진행 현황에 조작·임시 수치·미확인 사항 기록.

## 핵심 기준

플레이어 공격 10, 방어 5, 체력 100, 이동 4.0; 검 공격력 +12, 간격 0.55초, 사거리 1.7, 전방 90도, 최대 3대상; 슬라임 체력 50, 공격 8, 방어 2. 일반 피해는 `max(1, floor(공격력 × 배율 − 방어력 × 0.5))`, 치명타는 일반 피해의 1.5배를 다시 내림. 검 비치명타는 21 피해.

검증 시 경계 밖 대상, 다중 충돌체, UI 위 누름과 드래그, 사망 중 입력, 반복 재시작도 확인한다. 세부 슬라임 행동과 표시값은 임시값으로 문서화한다.
