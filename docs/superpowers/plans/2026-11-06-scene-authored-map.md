# 씬 하이어라키 기반 맵 전환 계획

**목표:** 바닥과 경계가 Play 전에 전투 씬 하이어라키에 존재하고 Unity에서 편집한 영역을 게임이 사용하도록 합니다.

**방식:** 전투 씬에 Map 루트, Map Floor와 그 자식인 네 경계 스프라이트를 직렬화합니다. 바닥을 이동하거나 확대하면 자식 경계도 따라갑니다. 플레이 영역은 씬 바닥과 경계의 실제 월드 범위를 읽으며 실행 중 맵 오브젝트를 생성하거나 배치를 덮어쓰지 않습니다. 기존 씬 GUID·설정 에셋과 게임플레이 값은 보존합니다.

---
## 검증

- [x] Play 전 씬의 Map·바닥·네 경계와 스프라이트 참조 확인.
- [x] 바닥을 이동·확대한 경우 이동·카메라·조준 범위가 편집한 맵과 일치하고 재시작 시 중복되지 않는지 확인.
- [x] 맵 필수 오브젝트 누락 시 자동 생성하지 않고 오류를 표시하는지 확인.
- [x] 기존 검·슬라임·설정·UI·장애물 차단의 회귀 테스트와 씬 저장·재열기 검증.
- [ ] 실행·설계·일차별 문서 정리 후 커밋·푸시.

---
## 이관 원칙

기존 설정 에셋의 맵 반폭 필드는 사용자 데이터 보존을 위해 남기지만 씬 기반 맵의 크기 기준으로 사용하지 않습니다. 실제 맵 영역은 하이어라키에 배치된 바닥과 경계를 기준으로 합니다. 내부 벽의 이동 충돌은 후속 구현 항목입니다.
