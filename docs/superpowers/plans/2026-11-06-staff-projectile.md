# 14일차 지팡이 폭발 공격 계획

**목표:** 설정 에셋에서 지팡이를 선택해 커서 방향 마법탄을 발사하고, 적과 충돌하거나 사거리 끝에 도달하면 범위 피해를 한 번 적용합니다.

**기획 기준:** 지팡이 공격력 +8, 간격 0.90초, 사거리 5.5, 폭발 반경 1.1, 최대 4대상, 속도 초당 9(기획서 예시). 기본 공격 배율 1.0, 마나 소모 없음. 레벨 1 비치명타는 슬라임에게 17 피해. 발사 순간 방향 고정, 공통 피해 계산과 공격당 대상 중복 방지 사용.

**임시 정책:** 내부 장애물이나 씬 외곽에 먼저 닿으면 벽을 넘지 않고 마법탄을 소멸하며 폭발시키지 않습니다. 적과 사거리 끝에서만 폭발합니다. 폭발은 적 중심이 반경 안에 있는 살아 있는 대상을 거리순 최대 4명까지 선택하고, 폭발 중심에서 장애물에 가려진 대상은 제외합니다. 충돌 동률은 벽 우선. 사망·재시작 시 투사체와 효과를 정리합니다. 변경 가능한 위치와 검증 범위를 문서화합니다.

맵은 사용자가 씬 하이어라키에서 편집한 오브젝트를 그대로 사용하며 실행 코드로 생성하거나 수정하지 않습니다. 무기 교체 UI는 15일차에 구현합니다.

## 검증

- [x] 적에 닿거나 최대 사거리에 도달할 때 폭발하고 중심선·반경·최대 4대상·대상당 1회·17 피해를 확인합니다.
- [x] 장애물·씬 경계에서 마법탄이 멈추고 벽 너머 피해가 생기지 않는 임시 정책을 확인합니다.
- [x] 발사 방향 고정, 고속 연속 충돌, 무관한 트리거, UI 차단·사망·재시작을 확인합니다.
- [x] 기존 검·활·씬 맵 전체 회귀 및 씬 편집 보존을 확인하고 문서화·커밋·푸시합니다.
