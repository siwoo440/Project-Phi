# 23일차 내부 장애물 충돌 구현 계획

**목표:** 플레이어 일반 이동과 일반 적 5종의 이동·돌진이 씬에 배치된 `PhiObstacle` 비트리거 벽을 통과하지 않도록 한다.

**방식:** 기존 회피 충돌은 보존하고, 플레이어와 적이 공유하는 연속 사각형 이동 검사를 추가한다. 일반 이동은 접촉면을 따라 이동하고, 고정 방향 돌진은 최초 벽에서 중단한다. 늑대의 경로 표시도 실제 벽까지 제한한다. 시험용 내부 벽은 씬 하이어라키에 직접 저장하고 실행 중 맵을 생성하지 않는다.

**검증:** 가상 입력과 실제 플레이 모드의 벽에서 일반 이동·대각선 미끄러짐·뒤로 이동·트리거 통과·고속 이동을 확인한다. 다섯 적의 추격과 슬라임·늑대의 돌진, 벽 뒤의 플레이어 피해 방지, 원형 벽과 기존 회피 회귀를 검사한다. 수정 전 실패를 기록하고 수정 후 전체 편집·플레이 모드를 별도 프로젝트 복사본에서 실행한다.

**제약:** C#은 Allman 형식과 각 코드 줄의 짧은 한글 주석을 사용한다. 기존 맵과 설정 값을 보존하고 씬에는 내부 벽 한 개만 추가하며 성능·실제 화면·실물 입력의 미검증 여부를 기록한다.

**실행 결과:** 수정 코드에서 벽 이동 시험 10개가 통과했습니다. 이전 커밋을 검증 복사본에 적용해 같은 시험을 실행했을 때 벽 통과 사례 9개가 실패하고 트리거 통과 사례 1개가 통과했습니다. 기존 궁수 사망 시험의 0.6초 프레임 고정 실패를 재현한 뒤 실제 사망을 제한 시간 안에서 기다리도록 수정했고 긴 프레임 재시험이 통과했습니다. 위치·크기·그림과 시작 설정이 변경된 별도 프로젝트에서 편집 모드 32개와 플레이 모드 183개가 통과했습니다. 실제 화면·실물 입력·성능은 미검증입니다.
