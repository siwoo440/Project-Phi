# 11~12일차 충돌 구분과 검 시야 차단 계획

**목표:** 기존 공통 피해와 검 부채꼴을 유지하면서 전투 대상과 장애물을 Unity 레이어로 구분하고 장애물 뒤의 대상에게 검 피해가 전달되지 않도록 합니다.

**범위:** 기존 빈 레이어 8~10에 PhiObstacle·PhiPlayer·PhiEnemy를 지정하며 현재 레이어와 전역 충돌 행렬은 보존합니다. 검 판정은 유효한 대상마다 플레이어 중심에서 대상 중심까지 장애물 레이어의 비트리거 충돌체를 검사하고, 가려진 대상은 대상 수 상한 계산 전에 제외합니다. 초기 시험 씬에는 내부 장애물을 추가하지 않습니다.

---
## 검증

- [x] 벽이 없는 대상에게 21 피해와 공격당 최대 세 대상, 중복 방지를 검증합니다.
- [x] 장애물 뒤는 차단하고 앞은 적중하며, 다른 레이어와 트리거는 차단하지 않는지 확인합니다.
- [x] 가려진 가까운 적이 유효 대상의 세 자리 중 하나를 차지하지 않는지 확인합니다.
- [ ] 전체 편집·플레이 모드 회귀 테스트 후 문서를 갱신하고 커밋·푸시합니다.

## 임시 정책과 후속 사항

시야 차단은 대상 중심선 기준입니다. 플레이어·슬라임의 내부 장애물 이동 충돌과 실제 맵의 벽 배치는 별도 구현이 필요합니다. 무기 투사체·지팡이는 이후 일차에서 구현합니다.
