# 개발 계획

핵심 흐름은 마을 준비 → 전투·탐험·채집 → 귀환·보상 정산 → 제작·판매·성장 → 재출정입니다. 각 단계는 실제 실행 가능한 상태를 유지하며 진행합니다.

---
## 단계별 목표

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| 1 | 플레이어·검·슬라임 최소 전투 | 이동·조준·공격·피격·사망·재시작이 연결됨 |
| 2 | 무기 3종·공용 스킬 3개·회피·일반 적 5종·오우거 | 무기·스킬·적의 역할 차이를 플레이로 확인 |
| 3 | 던전 구역·목표·귀환·보상 | 한 번의 출정을 시작하고 정산까지 완료 |
| 4 | 임시·영구 성장·인벤토리·장비·저장 | 다음 출정과 재실행 시 유지·초기화가 정확함 |
| 5 | 채집·제작·골드·NPC 상점·납품 | 획득 → 제작 또는 판매 → 재투자 가능 |
| 6 | 수동 경제 이벤트 3종·로그·밸런스 | 이벤트 전후 활동 선택과 수입 비교 |
| 7 | 성능·사용성·통합 검증 | 밀집 전투와 반복 출정에서 주요 오류 해결 |

마을 1개, 전투 지역 1개, 던전 1개를 목표로 하되 작은 테스트 공간에서 먼저 검증합니다. 60작업일 일정은 참고 계획이며 진행 상태와 작업량에 따라 갱신합니다.

---
## 첫 단계 완료 기준

1. 테스트 씬에서 WASD 이동과 대각선 정규화, 카메라 추적, 독립적인 마우스 조준을 확인합니다.
2. 좌클릭 1회와 홀드 공격의 간격, 전방 부채꼴 판정과 공격당 대상 중복 방지를 확인합니다.
3. 슬라임의 접근·공격·피격·사망과 플레이어의 피격·체력 표시·사망을 확인합니다.
4. UI를 클릭해도 공격하지 않고 재시작 시 전투 상태가 초기화되는지 확인합니다.
5. 레벨 1 플레이어의 검 비치명타가 슬라임에게 21 피해를 주고 3회 적중으로 처치되는지 확인합니다.

첫 전투가 동작한 뒤 간단한 밀집 시험을 시작합니다. 일반 전투 60 FPS를 목표로 50마리부터 100마리 이상까지 부하를 시험하며 기준 PC·해상도·이펙트 수와 통과 조건은 별도로 정합니다.

---
## 기능 구현 전 보완할 규칙

- 첫 스킬 3개, 아이템·전리품, 시작 지급품과 골드
- 던전 구역·목표·개방·보스 활성화·클리어·귀환 조건
- 성공·사망·포기·게임 종료 시 보상과 저장 처리
- 영구 성장과 출정 중 임시 성장, 강화 카드의 등장·중복·상한
- 공격과 회피의 타이밍·취소·자원 소모, 적 행동과 보상 데이터
- 채집·제작, NPC 가격·재고·납품, 인벤토리·UI 규칙
- 에셋 규격과 기능·성능 검증 조건

첫 스킬 시험 조합은 화염탄·회오리 베기·치유의 빛을 추천안으로만 기록합니다. 최신 기획서에서 다른 결정이 확인되면 그 결정을 따릅니다. 유저 거래소·캐시·AI 자동 경제 조정·협동 플레이는 후속 단계로 둡니다.
