# 설계 결정

이 문서는 첫 구현에 채택한 기준과 확인이 필요한 기획 사항을 구분합니다. Google 기획서의 전체 탭 계층과 관련 본문 1.4, 1.5, 1.9~1.12, 1.12.12, 1.14, 6.4를 확인했습니다. 나머지 본문의 확인 여부는 별도로 관리합니다.

---
## 첫 구현 기준

- 장르는 2D 탑뷰이며 초기 플랫폼은 Windows PC, 실행 방식은 싱글 플레이와 로컬 저장입니다.
- WASD로 이동하고 대각선 이동속도를 정규화합니다. 마우스 조준은 이동 방향과 독립적입니다.
- 좌클릭은 일반 공격이며 홀드 시 공격 간격에 따라 반복합니다. UI 클릭은 전투 공격으로 전달하지 않습니다.
- Q/E/R은 서로 다른 공용 스킬을 장착하는 슬롯입니다. 회피는 Shift, 상호작용·수집은 F입니다. 이 조작의 후속 구현 여부는 진행 현황에서 관리합니다.
- 던전 진행은 시간별 강제 몬스터 교체가 아니라 구역 진입·목표 달성·오브젝트 상호작용 등 조건을 기준으로 합니다.
- 캐릭터·무기·적 등의 설정과 실행 상태를 분리하고 공통 피해 계산을 한 경로에서 처리합니다.
- 슬라임의 기획상 행동은 느린 접근 후 몸을 부풀려 예고하고 짧게 돌진하는 것입니다.

## 전투 기준값

| 항목 | 값 |
|---|---|
| 레벨 1 기본 공격력·방어력 | 10·5 |
| 기본 최대 체력·마나·스태미나 | 100·50·100 |
| 기본 이동속도 | 초당 4.0 월드 단위 |
| 최종 공격력 | 기본 공격력 + 무기 공격력 + 기타 장비 공격력 |
| 슬라임 체력·공격력·방어력 | 50·8·2 |

| 무기 | 공격력 보너스 | 공격 간격 | 사거리 | 기본 판정 |
|---|---:|---:|---:|---|
| 검 | +12 | 0.55초 | 1.7 | 전방 90도 부채꼴, 최대 3대상 |
| 활 | +10 | 0.70초 | 7.0 | 직선 투사체, 최초 1대상 |
| 지팡이 | +8 | 0.90초 | 5.5 | 폭발 반경 1.1, 최대 4대상 |

일반 공격은 마나를 소비하지 않고 한 공격에서 같은 적에게 의도하지 않은 중복 피해를 주지 않습니다. 시험 시작 무기는 `PrototypeSettings` 에셋의 `startingWeapon`에서 검·활·지팡이를 선택합니다. 기본값은 검이며 인게임 무기 교체는 아직 구현하지 않았습니다. 첫 전투의 공격은 피해 검증을 위해 비치명타로 고정하며 치명타 확률과 마나·스태미나의 실제 상태 처리는 후속 작업입니다.

피해 계산은 문서 `1.11.3`의 단계별 버림을 첫 구현의 임시 기준으로 사용합니다.

- 일반 피해: `max(1, floor(최종 공격력 × 공격 배율 − 대상 방어력 × 0.5))`
- 치명타 피해: `floor(일반 피해 × 1.5)`
- 공격 배율 1인 레벨 1 검 비치명타는 슬라임에게 `floor((10 + 12) − 2 × 0.5) = 21` 피해를 주며 3회 적중으로 처치합니다.
- 같은 조건의 활 비치명타는 `floor((10 + 10) − 2 × 0.5) = 19` 피해를 줍니다.
- 같은 조건의 지팡이 비치명타는 `floor((10 + 8) − 2 × 0.5) = 17` 피해를 줍니다.

## 첫 전투 임시값

슬라임 행동의 세부 수치와 시험 배치 수는 기획에서 정해지지 않아 전투 흐름을 시험할 수 있도록 임시로 정했습니다. 제공된 `Assets/Phi/Data/PrototypeSettings.asset`에서 조정합니다.

| 항목 | 임시값 |
|---|---:|
| 이동속도 | 1.5 월드 단위/초 |
| 공격 시작 거리 | 0.9 월드 단위 |
| 공격 간격 | 1.2초 |
| 공격 예고 | 0.4초 |
| 돌진 거리·속도 | 0.8 월드 단위·초당 5 월드 단위 |
| 돌진 적중 거리 | 0.65 월드 단위 |
| 초기 슬라임 수 | 3마리 |

활은 발사 순간의 조준 방향을 유지하는 직선 비관통 투사체이며 최초 적 또는 장애물에서 종료합니다. 속도 초당 14월드 단위는 기획서 데이터 표의 시험 예시이고 `PrototypeSettings`에서 조정합니다. 플레이어 중심 발사, 0.1×0.1월드 단위 화살 도형과 충돌 반경 0.05, 적과 벽의 동률 시 벽 우선은 임시 정책입니다. 슬라임의 사각 충돌체는 현재 도형과 같은 크기를 사용합니다. 씬 맵 외곽 경계도 화살을 종료합니다. 낮은 FPS에서 이동 중인 적과 화살의 상대 운동으로 생기는 스침 판정은 미검증입니다.

지팡이는 +8 공격력, 0.90초 간격, 사거리 5.5, 반경 1.1, 최대 4대상을 사용하며 마나를 소비하지 않습니다. 마법탄 속도 초당 9월드 단위는 기획서 데이터 표의 시험 예시입니다. 적에 닿거나 사거리에 도달하면 폭발합니다. 내부 벽과 씬 외곽에 먼저 닿으면 폭발하지 않고 소멸하며, 폭발 중심에서 벽에 가려진 대상은 제외합니다. 이 벽 처리 방식은 임시 정책입니다.

폭발은 적의 중심이 반경 안에 있는 생존 대상을 중복 제거한 뒤 폭발 중심에 가까운 순서로 최대 4명에게 적용합니다. 거리 동률은 슬라임 생성 순서를 사용합니다. 적과 충돌했을 때 폭발 기준은 접촉면이 아닌 충돌 순간의 마법탄 중심입니다. 플레이어 중심에서 발사하는 청색 도형의 크기 0.1월드 단위, 충돌 반경 0.05, 원형 효과 지속시간 0.15초는 임시값입니다. 효과 링은 실제 판정 반경보다 약간 안쪽의 근사 표시입니다. 낮은 FPS에서 이동 중인 적과 마법탄의 상대 운동으로 생기는 스침 판정은 미검증입니다.

시험 공간은 기본 중심 `(0, 0)`, 가로 반폭 10·세로 반높이 6 월드 단위인 사각형이며 기본 테두리 두께는 0.12입니다. 크기와 두께는 조작감을 시험하기 위한 임시값입니다. 맵은 씬의 `Map > Map Floor > Boundary Top / Bottom / Left / Right`에 저장되며 실행 시 맵을 생성하지 않습니다. 바닥을 이동·크기 조절하면 자식 경계도 이동·비례 확대됩니다. 바닥과 경계는 회전하지 않고 축에 맞춥니다. 실제 배치된 바닥과 경계가 판정 기준이며 기존 `PrototypeSettings`의 `mapHalfWidth`, `mapHalfHeight`는 데이터 보존용으로 남기고 판정에 사용하지 않습니다.

플레이어와 슬라임의 도형 전체가 테두리 안에 머물도록 각각의 최대 반폭을 반영합니다. 카메라는 화면비와 맵 크기에 맞춰 직교 시야를 최대 6에서 줄이고 맵 안에서 플레이어를 추적합니다. 이 시야 기준도 임시값입니다. 조준 표시 길이는 경계에서 줄이고 체력 막대는 본체 안쪽에 표시합니다.

검은 `PhiObstacle` 레이어의 비트리거 Collider2D가 플레이어와 적의 중심선을 가리면 해당 적에게 피해를 주지 않습니다. 가려진 적은 최대 적중 수에 포함하지 않습니다. `PhiPlayer`와 `PhiEnemy` 레이어도 구분하며 첫 씬에는 내부 장애물을 추가하지 않았습니다. 플레이어와 적의 내부 장애물 이동 충돌은 구현되지 않았습니다. 위 임시값은 플레이와 성능 검증 후 조정이 필요합니다.

## 후속 결정 사항

장비 개별 인스턴스와 아이템 템플릿, 영구 저장 데이터와 출정 임시 상태를 분리하고 드롭·제작·상점·인벤토리를 공통 ID로 연결합니다. 세부 저장 구조는 해당 기능을 만들기 전에 확정해야 합니다. 적과 투사체가 많아지는 단계에서 풀링과 생성·해제 비용을 검토합니다.

전달문에 설명된 참고 화면의 강화 +11, 레전드 등급, 돌진 베기와 예시 수치는 확정 데이터가 아닙니다. 현재 초기 강화 계획은 +0~+5이고 등급은 일반·고급·희귀·영웅이며 첫 프로토타입은 일반 등급을 우선합니다. 참고 이미지 실물은 확인하지 못했습니다.
