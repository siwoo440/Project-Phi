# 프로젝트 π

Windows PC를 대상으로 하는 2D 탑뷰 싱글 플레이 생존형 액션 RPG입니다. 첫 개발 목표는 플레이어와 슬라임이 싸우는 최소 전투 프로토타입입니다.

---
## 개발 환경

- Unity 에디터: 6000.3.21f1 (`ProjectSettings/ProjectVersion.txt` 기준)
- 입력 패키지: Input System 1.20.0
- 렌더링: Universal Render Pipeline 2D
- 현재 작업 폴더: `D:\Project-Phi`. Git `main`을 원격 저장소에 연결했습니다.

---
## 실행과 조작

1. Unity Hub에서 이 폴더를 기존 프로젝트로 추가하고 위 버전으로 엽니다.
2. 컴파일이 끝나면 메뉴 `Phi > Open Combat Prototype`을 선택합니다. 제공된 `Assets/Phi/Scenes/CombatPrototype.unity`를 열고 빌드 씬 목록에 등록합니다. 씬이 없으면 오류를 표시하며 씬을 만들지 않습니다. 설정 에셋은 `Assets/Phi/Data/PrototypeSettings.asset`입니다.
3. `Assets/Phi/Data/PrototypeSettings.asset`의 `Starting Weapon`에서 `Sword`, `Bow`, `Staff` 중 하나를 선택한 뒤 Play를 누릅니다. 기본값은 `Sword`입니다. 사망 화면의 `RESTART` 버튼으로 씬을 다시 불러옵니다.

프로젝트를 열었을 때 기본 `SampleScene`이 보인다면 `Assets/Phi/Scenes/CombatPrototype.unity`를 열거나 `Phi > Open Combat Prototype`을 선택한 뒤 Play를 누릅니다. 전투 씬을 빌드의 첫 씬으로 등록했으며 기존 `SampleScene`도 유지합니다. Unity 프로젝트 복사본에서 편집 모드와 플레이 모드 자동 테스트를 실행했습니다. 실제 마우스를 이용한 수동 플레이는 아직 검증하지 않았습니다.

전투 씬의 맵 바닥과 경계, 시험용 내부 벽은 Play 전부터 하이어라키에 있습니다. 플레이어·적·전투 UI는 Play할 때 생성됩니다. 프로젝트 복사본에서 Windows 빌드에 성공했으나 생성된 빌드 폴더는 요청에 따라 삭제했습니다. 당시 빌드의 실제 실행과 수동 조작은 검증하지 않았습니다.

기획서의 검·활·지팡이 이미지는 화면 하단 무기 버튼에, 슬라임 점액 이미지는 슬라임 사망 시 생성되는 시험 전리품에 사용합니다. 그림이 없을 때는 기존 도형과 글자로 표시합니다. 플레이어·적 본체와 애니메이션은 여전히 임시 도형입니다.

제공된 전투 설정에는 슬라임 3마리와 고블린·스켈레톤 궁수·오크 전사·늑대 각 1마리가 지정돼 있습니다. 슬라임은 몸을 부풀린 뒤 돌진하고, 고블린은 무기를 들어 예고한 뒤 근접 베기를 합니다. 궁수는 거리를 유지하며 활을 당긴 뒤 직선 화살을 쏘고, 오크는 도끼를 들어 예고한 뒤 전방을 강타합니다. 늑대는 몸을 낮추고 경로를 표시한 뒤 도약합니다. `PrototypeSettings`에서 적 수와 행동 시험값을 조절할 수 있습니다. 새 적 수 필드가 없는 기존 설정에서는 해당 적 수가 0입니다. 슬라임 외 적의 정식 보상은 아직 없습니다.

적 스폰 위치는 `Map > Map Floor > Spawn Areas > Initial`과 `Encounter`의 자식 오브젝트에 저장돼 있습니다. 각 지점의 `Enemy Spawn Point`에서 적 종류를 바꾸고 Transform으로 위치를 조절합니다. 시작 적 수는 기존 설정을 따르며, 맵 오른쪽 아래의 반투명 노란 `Encounter Trigger`에 들어가면 추가 지점마다 해당 적이 한 번 등장합니다. 전투 루트의 `Max Living Enemies` 기본 시험값은 20입니다. 상한에 도달하거나 지점이 벽·플레이어·생존 적과 겹치면 남은 요청은 안전한 자리가 날 때까지 대기합니다. 지점을 맵 밖으로 옮기면 임의로 위치를 보정하지 않습니다. 재시작하면 구역과 요청이 초기화됩니다. 적의 장애물 우회 경로와 정식 던전 목표 조건은 아직 없습니다.

| 조작 | 동작 |
|---|---|
| WASD | 이동. 대각선 속도 정규화 |
| 마우스 | 이동 방향과 독립적으로 조준 |
| 좌클릭 | 장착한 검·활·지팡이의 공격. 누르고 있으면 무기별 공격 간격에 따라 반복 |
| Q / E / R | 각 슬롯에 장착된 구현 스킬 사용. 기본 시험 조합은 화염탄·회오리 베기·치유의 빛 |
| Shift | 이동 키 방향으로 회피. 이동 입력이 없으면 현재 마우스 조준의 반대 방향으로 회피 |
| F | 표시된 가장 가까운 시험 전리품 하나 수집. 누르고 있어도 반복되지 않음 |
| 화면 하단 무기 버튼 | 시험 공간에서 검·활·지팡이 선택 |

전투 수치는 `PrototypeSettings` 에셋에서 조정합니다. 화면 하단의 세 버튼으로 플레이 중 무기를 선택하며 에셋의 시작 무기는 변경하지 않습니다. 재시작하면 에셋의 시작 무기로 돌아갑니다. 맵은 씬의 `Map > Map Floor > Boundary Top / Bottom / Left / Right`와 `Internal Wall`로 저장돼 있습니다. 내부 벽은 `PhiObstacle` 레이어의 비트리거 `BoxCollider2D`이며 Play 전에 하이어라키에서 위치와 크기를 조정할 수 있습니다. 플레이어와 적은 내부 벽을 통과하지 않고, 일반 이동은 벽을 따라 움직이며 슬라임 돌진과 늑대 도약은 벽 앞에서 멈춥니다. `Map Floor`를 이동하거나 크기를 조정하면 자식 경계도 함께 변경됩니다. 바닥과 경계는 회전하지 않고 축에 맞춰 배치합니다. 기본 시험 공간은 중심 `(0, 0)` 기준 가로 반폭 10·세로 반높이 6월드 단위입니다. 이전 `mapHalfWidth`, `mapHalfHeight` 값은 에셋에 보존되지만 맵 크기에는 사용하지 않습니다. 검증 여부는 [진행 현황](docs/진행현황.md)을 확인하세요.

공용 스킬의 Q/E/R 시작 조합은 전투 전에 `PrototypeSettings` 에셋에서 선택합니다. 마을과 준비 화면은 아직 없어 게임 안에서 스킬을 변경할 수 없습니다. 기본값인 화염탄·회오리 베기·치유의 빛은 임시 시험 조합입니다. 실행 상태는 설정과 분리되며 무기를 바꿔도 유지되고, 재시작하면 시작 설정을 다시 읽습니다. 현재 시험에서는 세 슬롯에 서로 다른 유효한 스킬이 필요합니다. 빈 슬롯·목록 밖 값·중복은 해당 슬롯만 비활성화하고 오류를 표시하며 기존 전투는 계속됩니다. 빈 슬롯의 최종 허용 규칙은 정해지지 않았습니다.

시험 후보는 방향형 화염탄·얼음 파편·방패 치기·관통 사격·순간 이동, 지정형 번개 사슬·속박 덩굴·마력 폭발, 자기 중심형 회오리 베기·치유의 빛·수호막·질주입니다. 이 목록은 획득이나 해금을 뜻하지 않습니다. 화염탄·회오리 베기·치유의 빛은 발동하며 나머지 9종은 아직 미구현으로 마나를 소비하지 않습니다. 기본 최대 마나는 50이고 초당 3씩 회복합니다. 화면에는 마나와 슬롯별 대기시간을 영문으로 안내합니다. 실제 화면의 글자 가독성과 조작은 아직 확인하지 않았습니다.

회피는 시작 즉시 스태미나 25를 사용하고 임시 무적 상태가 되며, 이동은 다음 프레임부터 시작합니다. 기본 최대 스태미나는 100이고 회피 이동이 끝난 뒤 1초 후 초당 15씩 회복합니다. 회피 중 새로운 일반 공격과 스킬 입력은 차단합니다. 회피와 장애물의 실제 조작감은 아직 수동 검증하지 않았습니다.

슬라임 사망 시 시험용 슬라임 점액이 한 개 생성됩니다. 기본 반경 1.5월드 단위 안에서 벽에 가리지 않은 가장 가까운 대상을 표시하며 F를 한 번 누르면 전리품 한 개를 수집합니다. 화면의 `TEST LOOT`는 이번 전투의 임시 횟수로 재시작 시 초기화되며, 고정 드롭과 반경은 확정 보상이 아닙니다. NPC·문·상자 작동, F 홀드 광역 줍기와 정식 인벤토리·저장·보상 정산은 미구현입니다. 실제 화면과 수동 조작은 확인하지 않았습니다.

체력·스킬·상호작용 HUD와 무기 버튼 위에서 시작한 클릭은 전투 공격으로 전달되지 않습니다. 이후 추가할 인벤토리·설정 같은 화면의 루트에 `CombatInputFocus`를 붙이면 화면이 활성화된 동안 전투 입력이 차단됩니다. 텍스트 입력 중에도 전투 입력을 차단합니다. 화면을 열어도 게임 시간과 적 행동은 계속되며, 입력 차단을 거친 마우스 홀드는 놓은 뒤 새로 클릭해야 공격합니다. 인벤토리·설정 화면 자체는 아직 없습니다.
